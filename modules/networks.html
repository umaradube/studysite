IPv4 subnet calculator

Enter an address and CIDR prefix to check network address, broadcast, mask, and usable range. Designed for conventional /1–/30 subnets.

The study guide uses the formula 2^host bits − 2. This calculator uses that formula for standard IPv4 host subnets and does not cover special /31 point-to-point or /32 host routes.

Try these exam examples

192.168.10.77/27 → network .64, broadcast .95, 30 usable.

10.0.5.130/26 → network 10.0.5.128, broadcast 10.0.5.191, 62 usable.

172.16.10.200/28 → network 172.16.10.192, broadcast 172.16.10.207, 14 usable.
